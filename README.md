# React + Vite

Este modelo oferece uma configuração mínima para utilizar o React no Vite, com HMR e algumas regras do ESLint.

Atualmente, dois plugins oficiais estão disponíveis:

@vitejs/plugin-react utiliza o Oxc
@vitejs/plugin-react-swc utiliza o SWC

## Compilador do React

O React Compiler não está habilitado neste modelo devido ao seu impacto no desempenho de desenvolvimento e de build. Para adicioná-lo, consulte [esta documentação](https://react.dev/learn/react-compiler/installation).

# 🌦️ Previsão do Tempo com IA

Este projeto é uma aplicação web simples e interativa que permite consultar a previsão do tempo de qualquer cidade e receber sugestões de roupas com base nas condições climáticas utilizando Inteligência Artificial.

---

## 🚀 Tecnologias Utilizadas
- HTML5 → Estrutura da aplicação
- CSS3 → Estilização e responsividade
- JavaScript → Lógica da aplicação
- API OpenWeather → Dados climáticos em tempo real
- API Groq (IA) → Geração de sugestões inteligentes

## ✨ Funcionalidades
- 🔍 Buscar clima por nome da cidade
- 🌡️ Exibir temperatura em °C
- 💧 Mostrar umidade do ar
- 🌤️ Exibir descrição do clima e ícone
- 🎤 Busca por voz (Web Speech API)
- 🤖 Sugestão de roupa com IA baseada no clima
